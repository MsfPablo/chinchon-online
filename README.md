# Chinchón online

Chinchón para dos con baraja española. Los dos jugadores escriben el mismo
código y se conectan directamente entre navegadores (WebRTC). Sin cuentas,
sin registro y sin servidor de partidas.

## Modos de juego

- **Clásico** — cierras cuando tus cartas sueltas suman 5 o menos.
- **Trío y escalera** — cierras solo con un trío y una escalera de 4 del mismo palo.

El anfitrión (el primero que entra con el código) elige el modo; el segundo lo hereda.
